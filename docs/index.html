Installation

Deux façons de l'installer

Dans les deux cas, il faut une build source d'Equicord — l'installeur classique ne peut pas charger de plugin custom.

Réglages Discord Recommandé
  1. Ouvre Discord avec Equicord installé en build source.
  2. Va dans Réglages → UserPlugins.
  3. Colle l'URL du dépôt et installe.
  4. Les mises à jour futures se font depuis ce même écran.
# URL à coller dans UserPlugins
https://github.com/jahsohsaniOFF/Boby
zsh — manuel
  1. Clone le dépôt dans src/userplugins.
  2. Build en mode dev et injecte.
  3. Mise à jour plus tard : git pull puis rebuild.
$ git clone https://github.com/jahsohsaniOFF/Boby.git src/userplugins/boby
$ cd equicord
$ pnpm build --dev
$ pnpm inject

Mises à jour automatiques

Une fois installé via UserPlugins, Discord vérifie l'état du dépôt et te notifie quand une nouvelle version est disponible.

Un clic suffit pour l'appliquer — pas besoin de retoucher au terminal.

!

Prérequis & prudence

Equicord doit être compilé depuis les sources (voir Equicord/Equicord) — l'installeur grand public ne suffit pas.

N'installe des userplugins que depuis des sources en qui tu as confiance : ce code s'exécute avec un accès natif à ton système.
