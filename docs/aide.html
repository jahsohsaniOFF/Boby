Installer Boby, étape par étape

Choisis ta méthode ci-dessous. La première est recommandée si tu as déjà Equicord installé en build source.

Méthode 1 — Panneau UserPlugins

Recommandé

Depuis Discord, sans toucher au terminal.

1

Ouvre les réglages Discord

Assure-toi qu'Equicord est bien installé en build source (voir la page d'accueil si ce n'est pas encore fait).

▢
tuto-1-reglages.png
2

Va dans l'onglet UserPlugins

Il se trouve dans la liste de gauche des réglages Equicord, section UserPlugins.

▢
tuto-2-onglet.png
3

Colle l'URL du dépôt et installe

# URL à coller dans le champ d'installation
https://github.com/jahsohsaniOFF/Boby
▢
tuto-3-installation.png
4

C'est fait

Discord relance la build tout seul. Les futures mises à jour apparaîtront dans ce même onglet, avec une notification quand une nouvelle version sort.

▢

Méthode 2 — Manuelle

Si tu préfères tout faire depuis un terminal. Pas besoin de captures ici, ce ne sont que des commandes.

1

Clone, build, injecte

Depuis la racine de ta copie d'Equicord :

$ git clone https://github.com/jahsohsaniOFF/Boby.git src/userplugins/boby
$ pnpm build --dev
$ pnpm inject
2

Pour mettre à jour plus tard

$ cd src/userplugins/boby
$ git pull
$ cd ../../..
$ pnpm build --dev
$ pnpm inject

Pour ajouter une capture : remplace le contenu d'un bloc .shot-screen par une balise <img src="ton-fichier.png" alt="...">, et mets le fichier dans docs/ à côté de aide.html.
